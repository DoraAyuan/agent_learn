# Skill: code_debug

## Purpose
用于分析代码报错、定位问题并给出可执行的修复建议。

## When to use
当用户有以下需求时使用：
- 代码报错
- 程序无法运行
- 逻辑错误排查
- 环境问题（如依赖、路径）

## Input
用户提供：
- 报错信息（error message）
- 相关代码
- 运行环境（可选）

## Steps
1. 阅读报错信息，定位错误类型
2. 分析代码上下文
3. 判断问题属于哪一类：
   - 语法错误
   - 运行时错误
   - 环境问题
   - 逻辑问题
4. 给出具体修改方案
5. 如有必要，提供修正后的代码示例

## Output Format
请按照以下结构输出：

1. 错误原因分析
2. 具体问题位置
3. 修改建议
4. 修正后的代码（如需要）

## Constraints
- 不要只说“检查代码”
- 必须给出明确修改方法
- 优先提供可直接复制的修复代码
