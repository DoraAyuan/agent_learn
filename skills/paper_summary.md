# Skill: paper_summary

## Purpose
用于总结论文、综述或技术文章，提取核心信息并结构化输出。

## When to use
当用户有以下需求时使用：
- 总结论文内容
- 提取研究目标、方法、结果
- 关注某一部分（如深度学习方法）

## Input
用户提供：
- 论文内容（全文或摘要）
- 或者论文主题描述

## Steps
1. 识别论文的研究领域和主题
2. 提取研究背景和研究目标
3. 分析方法（模型、算法、数据集等）
4. 总结实验结果和结论
5. 如果用户有指定重点（如深度学习），优先展开

## Output Format
请按照以下结构输出：

1. 研究背景与问题
2. 方法（重点说明模型/算法）
3. 数据与实验设置
4. 结果与结论
5. 局限性（如果有）

## Constraints
- 不要胡编论文内容
- 如果信息不足，明确说明“信息不足”
- 输出要结构清晰，不要一大段文字
