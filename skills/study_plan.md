# Skill: study_plan

## Purpose
用于根据用户的目标、基础和时间，制定清晰可执行的学习计划。

## When to use
当用户有以下需求时使用：
- 制定学习路线
- 准备考试/面试
- 学习新技术（如深度学习、编程）

## Input
用户提供：
- 学习目标
- 当前基础
- 可用时间（每天/每周）

## Steps
1. 分析用户目标（短期/长期）
2. 评估用户当前水平
3. 拆分学习阶段（基础→进阶→实践）
4. 为每个阶段安排内容
5. 给出每日/每周计划建议

## Output Format
请按照以下结构输出：

1. 学习目标分析
2. 阶段划分
3. 每阶段学习内容
4. 时间安排建议
5. 注意事项

## Constraints
- 不要给过于空泛的建议
- 计划要具体到“可以执行”
- 根据用户基础调整难度
