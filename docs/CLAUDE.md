# docs 模块

## Module Responsibilities

`docs/` 目录存放项目的参考文档：

- **coding_standards.md**：项目编码规范执行标准，定义了命名、签名、Docstring、注释、文本语言、审查协议等详细规则
- **project_roadmap.md**：项目迭代路线图，从 v0.1 到 v2.0 的版本规划与技术能力覆盖

## 文档概览

### coding_standards.md

完整的编码规范，包含 10 个章节：

| 章节 | 内容 |
|------|------|
| 1. 核心原则 | 优先级、核心信条、术语定义 |
| 2. 文件与导入 | 文件命名、导入顺序、禁用 `import *` |
| 3. 命名 | PascalCase/snake_case/UPPER_SNAKE_CASE 规范 |
| 4. 签名与类型提示 | 参数类型、返回值类型、换行对齐 |
| 5. Docstring | 三双引号格式、字段块顺序、最小合法形态 |
| 6. 注释与括号 | 意图注释、括号使用场景 |
| 7. 文本语言 | 中英文分工、中文排版规范 |
| 8. 结构与职责 | 实现层面和界面链路的职责划分 |
| 9. 审查协议 | 结论分级、输出顺序、审查禁区 |
| 10. 快速检查清单 | 16 项检查要点 |

### project_roadmap.md

项目迭代路线图，包含：

- 各版本的代码架构设计
- 从 v0.1 到 v2.0 的迭代规划
- 技术能力覆盖度评估
